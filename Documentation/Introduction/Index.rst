**Abstract:**

This extension provides OAuth 2.0 authentication for TYPO3 installations, enabling secure backend login through various OAuth2 providers.

----

**What does it do?**

The OAuth2 extension enables:

* Secure backend authentication through OAuth2 providers
* Automatic backend user creation
* Control of admin permissions via OAuth resource servers
* Assignment of backend group memberships
* Support for multiple OAuth2 providers

----

**For whom is it useful?**

This extension is particularly useful for:

* Organizations using centralized authentication systems
* Teams working with external OAuth2 providers
* Projects requiring secure backend access
* Developers needing custom OAuth2 integration

----

**Why should you use it?**

Benefits include:

* Enhanced security through OAuth2 authentication
* Simplified user management
* Centralized authentication control
* Flexible provider integration
* Reduced password management overhead
